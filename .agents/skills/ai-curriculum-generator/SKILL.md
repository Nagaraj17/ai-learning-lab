### 7. Create Manual Exercises

Create manual exercises only for mathematics or mechanisms that materially
benefit from hand calculation.

For each exercise:

- use deliberately small numbers;
- provide all required input matrices/vectors;
- trace dimensions;
- include learner workspace before the solution;
- verify every expected result;
- connect the exercise directly to the current assignment.

Do not create manual exercises merely to satisfy structure.

### 8. Build the Implementation

Create the implementation only after the learning material and manual
prerequisites are complete.

The implementation must:

- build the week's core mechanism from first principles where practical;
- use small, inspectable examples first;
- include explanatory Markdown around code;
- map important code operations back to the mathematics;
- expose useful intermediate values and shapes;
- avoid monolithic solution blocks;
- distinguish expected behaviour from observed behaviour.

The learner should implement independently rather than simply copying
a generated final solution.

### 9. Experiment and Review

After the baseline implementation works:

- change at least one meaningful variable or assumption;
- predict the expected effect before running;
- record actual output;
- explain differences between expectation and observation;
- identify limitations exposed by the experiment.

Review conceptual understanding, mathematics, code comprehension and
debugging/what-if scenarios.

### 10. Reflection and Mastery

Complete the week only after the learner can:

- explain why the concept exists;
- explain the mechanism;
- trace the important mathematics and shapes;
- implement the core idea;
- explain experiment results;
- identify limitations;
- connect the topic backward and forward in the curriculum.

Update REVIEW.md, REFLECTION.md and mastery/progress tracking as appropriate.
