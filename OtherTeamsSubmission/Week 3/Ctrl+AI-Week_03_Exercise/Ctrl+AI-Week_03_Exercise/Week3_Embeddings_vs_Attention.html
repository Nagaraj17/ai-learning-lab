Why Embeddings Need Attention

Interactive Demo: Static vs Dynamic Representations

The Core Problem: One Vector, All Contexts

Question: In Week 2, you learned that "Receive" and "Restock" have similar embeddings because they appear in similar contexts.

But here's the problem: The same word "Receive" gets the SAME vector every time, regardless of what came before it.

❌ Week 2: Static Embedding

Same word → Always same vector

Sequence 1:
Shipment → Receive
[0.72, -0.15, 0.44, -0.28, 0.91, -0.12]
Sequence 2:
Forecast → Receive
[0.72, -0.15, 0.44, -0.28, 0.91, -0.12] ← IDENTICAL!
Problem: Can't tell these are different contexts

✅ With Attention: Context-Aware

Same word → Different vector per context

Sequence 1:
Shipment → Receive
[0.78, -0.12, 0.48, -0.24, 0.93, -0.09]
Attention: 80% Shipment
Sequence 2:
Forecast → Receive
[0.65, -0.22, 0.35, -0.35, 0.85, -0.18] ← DIFFERENT!
Attention: 60% Forecast
Solution: Blend previous context into embedding

Real Example: What This Means

When predicting what comes after "Receive":

❌ Without Attention
Shipment → Receive → ?
Model sees: "Receive"
Predicts: Restock (85%)
Forecast → Receive → ?
Model sees: "Receive" (SAME!)
Predicts: Restock (85%) ← WRONG!
✅ With Attention
Shipment → Receive → ?
Model sees: Receive + 80% Shipment
Predicts: Restock (95%) ✓
Forecast → Receive → ?
Model sees: Receive + 60% Forecast
Predicts: Verify (70%), Restock (30%) ✓
Key Difference: Attention lets the model "look back" and weight what came before. Same word, but different effective meaning based on context.

How Attention Works (Simple)

Attention is just a weighted blend of previous embeddings. The weights say "which previous word matters most?"

Step 1: Start with embeddings
Order = [0.15, 0.66, ...]
Shipment = [0.60, 0.44, ...]
Receive = [0.72, -0.15, ...]
→
Step 2: Ask "who matters?"
Which word is most
similar to Receive?
→ Shipment (65%)
Step 3: Blend them
0.10 × Order +
0.65 × Shipment +
0.25 × Receive
→
Step 4: New representation
Receive_with_context =
[0.78, -0.12, ...]
← Different!
The Formula:
context_embedding = Σ(weight_i × embedding_i)

Where weight_i = "how important is word i for predicting the next word?"

The Big Picture

Embeddings = "What is this word?"

Like a dictionary definition. Same word → same definition.

Attention = "What is this word right now?"

Like understanding context. Same word → different meaning based on what came before.

Bottom Line

❓ Question: "We have embeddings. Why do we need attention?"

✅ Answer: Because embeddings are frozen. Attention makes them fluid—adapting to each context.

Static Embeddings
  • ✓ Learned from data
  • ✗ Same every time
  • ✗ Misses context
  • ✗ Lower accuracy
With Attention
  • ✓ Learned from data
  • ✓ Different per context
  • ✓ Uses context
  • ✓ Higher accuracy

You need both: Embeddings + Attention
