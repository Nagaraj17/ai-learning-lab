📍 The Problem: Why Attention Was Only 60% Accurate

After implementing the attention mechanism, we discovered that while the static embedding model achieved 100% accuracy, the attention model only reached 60% accuracy. This was surprising because attention should help the model understand context.

The Question: If static embeddings work so well, why is attention struggling?

  • Confidence: Very low (~20-30%)

✓ Static Model (Week 2)

🔍 Root Cause Analysis

We identified 5 critical problems in the original implementation:

# Problem Impact Why It Happened
1 Incomplete Backward Pass Context embeddings never updated Gradients computed but not applied (code comment: "This would update context embeddings in a full implementation")
2 Learning Rate Too High Unstable training, oscillation 0.1 works for simple static model, but too aggressive for attention blending
3 Insufficient Epochs Premature convergence 50 epochs enough for static, not enough for attention mechanism
4 Fixed Blend Ratio Suboptimal weighting (70/30 fixed) Model couldn't adapt blend based on actual data
5 Gradient Damping Embeddings learned 38% slower Gradient multiplied by (1-alpha), reducing signal strength

🔬 Deep Dive: The Gradient Damping Problem

The most critical issue was how gradients flowed through the attention blending layer. Let's examine the mathematical problem:

❌ Original (Wrong) Implementation:

grad_base = (1 - self.attention_ratio) * grad_context_aware self.E[token_id] -= learning_rate * grad_base # With alpha = 0.7: # grad_base = (1 - 0.7) * grad = 0.3 * grad # ⚠️ Only 30% of gradient reaches the embedding!

This means if the correct gradient signal was 1.0, the embedding only received 0.3. It's like trying to learn with 70% of your hearing ability turned off!

✓ Fixed (Correct) Implementation:

grad_base = grad_context_aware # Full gradient self.E[token_id] -= learning_rate * grad_base # Now: Full gradient reaches embedding # Alpha is optimized separately as a learnable parameter # ✓ Fast, stable learning
Key Insight: Let the gradient flow completely to the embedding. The blend ratio (alpha) should be optimized as a separate learnable parameter, not used to dampen gradients. This is the critical distinction!

✨ The 5 Solutions Applied

Solution 1: Complete Backward Pass ✓

Before

if context_embeddings: grad_context_sum = ... # This would update context... # (comment shows it's incomplete)

After

for j, weight in enumerate(attn_weights): grad_context_emb = weight * grad_vec E[context_tokens[j]] -= lr * grad # Context embeddings now properly trained!

Why: Attention blending is more sensitive. Lower learning rate prevents oscillation.

Solution 3: More Training Epochs ✓

Why: Attention mechanism needs more iterations to converge. The lower learning rate also requires more epochs.

Solution 4: Learnable Blend Ratio ✓

Before: alpha = 0.70 (fixed)

After: alpha = learnable parameter

Why: Different problems need different blend ratios. Let the model learn what works best.

💡 Key Learnings from This Exercise

1. Gradient Flow is Critical

Never dampen gradients in a learnable way. Let the full signal reach your parameters. If you need to adjust weighting, do it as a separate learnable parameter (like alpha), not by multiplying gradients.

2. Learning Rate Matters More for Complex Mechanisms

Simple models (static embeddings) can tolerate higher learning rates. Complex mechanisms (attention) need lower learning rates and more careful tuning. The same hyperparameter doesn't work for both.

3. Architecture and Training Are Separate Concerns

The attention mechanism itself was correct, but the backward pass was incomplete. Always ensure:

  • ✓ All parameters get gradients
  • ✓ Gradient flow is complete
  • ✓ No gradients are accidentally dropped

4. Convergence Takes Time

With proper implementation, the model converges predictably. 200 epochs vs 50 epochs shows the difference between reaching convergence vs stopping early.

5. Why Alpha Converged to 0.19

The model learned to use only 19% context and 81% self-embedding. This makes sense because:

  • Each word ALWAYS maps to the same next word
  • Context doesn't add information value for this problem
  • The attention mechanism correctly identified this!

This is actually a sign the model is working correctly. It learned that attention isn't helpful for this specific problem.

Counterintuitive Insight: Sometimes simpler solutions (static embeddings) are better than complex ones (attention). The value of attention appears in problems where context matters. In a deterministic problem where each word always means the same thing, attention provides less value. But the mechanism works correctly—it just learned to downweight context appropriately.
