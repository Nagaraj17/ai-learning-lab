Now since we know that why Attention is used and what is Attention mechanism and Q, K and V are derived in Attention mechanism and how it adds contextual meaning to each word.

The attention mechanism where the Q, K and V are derived from the Same input sentence is called as Self Attention which we completed last week..

With the attention now we can compute the Q,K,V values in parallel and leverage GPUs.

Although Attention mechanism adds contextual meaning to the token representation, it is order blind!.


For example: 

Consider the order of  log events in the GPO, Normal Compliant sequence:

 
  -> [Contract, Order, Shipment, Invoice, Rebate]

(A GPO contract is established, Order is place, Goods are shipped, Invoice generate and Volume rebate claimed)

  Here Contract is at the position 0 where as the Rebate is at Position 4 

Now, lets shuffle the order of log events

  -> [Rebate , Invoice, Order, Contract, Shipment]
This is a audit risk compliant, Where Rebates are claimed at position 0 before contract or order exists- a potential fraud or an error in billing.

If we shuffle the tokens interestingly we see that the attention scores are the same which means it is missing the positional information, this is obvious we are calculating Q K V for each of the tokens with respect to the Embedding of each token and Embedding is just the General or the base representation of the token/word.


Therefore to preserve the position information with each contextual representation we would have to inject the positional information before calculating the Q, K, V values.

This is simply done by adding the Position-dependent vectors to token embeddings so that while the attention scores are calculated it takes the position into consideration.

What is Position-dependent vector and how is it calculated?

A Position-dependent vector is a vector containing position encodings in a dimensional space similar to the dimension of the token.

Usually the Position-dependent vector is calculated in many ways one of which is learned in similar ways as the embeddings.

Second which is most popular is using the Sinusoidal waves because of the following reasons.
We can always have bounded values no matter how long the sequence is will solve the explosion problem
Extrapolation of sequence lengths without training
It allows attention mechanism learn relative distance relationships 


Now lets take the QKV values now we know that Q = X * WQ where X is sequence matrix containing the Embeddings of the sequence.

Now Instead of the embeddings X(P) = (X(Embedding) + Position-dependent Vector  Where X(P) is Contextual representation along with Positional context

Now the model would know the difference when Rebate comes before Contract.
